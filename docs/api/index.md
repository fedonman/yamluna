# API reference

Most programs need only `from yamluna import YAML`. These pages cover the public methods and types used to read, edit, and write documents.

| Reference | Covers |
| --- | --- |
| [YAML](yaml.md) | Loading, saving, settings, and class registration |
| [Containers](containers.md) | Dictionaries and lists with comments and formatting |
| [Strings and numbers](scalars.md) | Types for choosing how a value is written |
| [Tag registry](registry.md) | Registering classes and sharing registrations |
| [Errors](errors.md) | Exceptions and source positions |

All types listed here are importable from `yamluna`. For examples, start with the [guides](../guide/index.md). For less common compatibility helpers, see the [source docstrings](https://github.com/fedonman/yamluna/tree/main/python/yamluna).
